☁️ Firebase Cloud Sync

Connect to Firebase to sync data across all devices in real-time. Create a free project at console.firebase.google.com

Quick Setup:
1. Go to Firebase Console → Create project
2. Realtime Database → Create database → Start in test mode
3. Project Settings → Copy API Key & Project ID
4. Paste the Database URL from the Realtime Database page

🎫 Service Log Connection

Connect to your Service Log Firebase project so tech visits scheduled here are sent as tickets directly to the Service Log dashboard. This is a separate Firebase project from chemical sync above.

What happens:
Each tech visit you create here gets written to the Service Log's tickets Firestore collection with source: "chem-dashboard" so you can spot where it came from.
